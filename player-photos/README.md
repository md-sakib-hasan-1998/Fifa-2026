# Player Photos

Upload player photos to **this folder** (`player-photos/`) in the GitHub repository.

## Naming Format

```
{team}_{player}.png
```

Both parts are **lowercase** with **underscores** replacing spaces.

### Examples

| Team | Player | Filename |
|------|--------|----------|
| Brazil | Neymar Jr | `brazil_neymar_jr.png` |
| Argentina | Lionel Messi | `argentina_lionel_messi.png` |
| France | Kylian Mbappé | `france_kylian_mbappe.png` |
| England | Harry Kane | `england_harry_kane.png` |
| Portugal | Cristiano Ronaldo | `portugal_cristiano_ronaldo.png` |
| Saudi Arabia | Salem Al-Dawsari | `saudi_arabia_salem_al-dawsari.png` |
| United States | Christian Pulisic | `united_states_christian_pulisic.png` |

## Rules

- Format: **PNG** preferred (JPG also works but keep extension `.png` in the URL stored in DB)
- Size: ideally **200×200 px** or larger, square crop
- The website automatically constructs the URL:
  `https://raw.githubusercontent.com/md-sakib-hasan-1998/Fifa-2026/main/player-photos/{team}_{player}.png`
- If a photo is missing the website shows the player's initials — no broken images.

## How to Upload

1. Go to your GitHub repo: https://github.com/md-sakib-hasan-1998/Fifa-2026
2. Open the `player-photos/` folder
3. Click **Add file → Upload files**
4. Drop in your photos with the correct names
5. Commit — the website picks them up instantly (no restart needed)
